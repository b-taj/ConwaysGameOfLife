# Conway's Game of Life

A C++ implementation of Conway's Game of Life built using raylib.

## What I Built

The main application is in:

`src/main.cpp`

The project includes:

- Conway's Game of Life simulation
- Neighbor detection
- Random grid generation
- Mouse interaction
- Pause/resume
- Clear grid
- Randomize grid
- Adjustable simulation speed
